# redis-subscriber - Use redis to update a master table in cas

This is a companion to the [@sassoftware/mcp-serverjs](https://github.com/sassoftware/restaf-demos/tree/mcp-serverjs) package, although it can be used with other mcp servers or other types of applicatoions.

## Requiremeents

A Docker Desktop or its equivalent. I will note that I have not tested this against others like podman - so make the appropriate changes

## Usage

Run this command

```sh
npm start
```
